An entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) competition on [make.fun](https://make.fun).

## What it does

`main.ts` (Node 22, TypeScript) writes a single roast line — at most 200 characters — roasting a smart fridge to `/output/entry.txt`.

## The roast

> My smart fridge's touchscreen froze during a firmware update — now it's a $3,000 night-light with strong opinions about my milk.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The output is deterministic: every run writes the exact same line.
